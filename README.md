# ПБА Gedeon Richter — сайт сборки отчётов

Локальный сайт: загружаете xlsx с ПБА → получаете готовый отчёт (план/факт по неделям
и площадкам, спрос по ключевым словам из Google, выводы от Клода) и кнопку «Скачать HTML».

## Как пользоваться

1. Двойной клик на **`start.bat`**. Откроется чёрное окно (это сервер, не закрывайте)
   и браузер на http://127.0.0.1:8765
2. Перетащите файл ПБА в первый блок.
3. Выберите месяц. Рядом с каждым месяцем видно, сколько недель закрыто и какое
   выполнение по закрытым.
4. Впишите ключевые слова в два блока:
   - **блок 1 — бренд и конкуренты**: первая строка это наш бренд (подставляется из
     файла), под ней до трёх конкурентов. В отчёте по этому блоку считается доля голоса
     в поиске и место по объёму запросов;
   - **блок 2 — категория**: самые широкие запросы (обычно 4). В отчёте это объём спроса
     в категории и какая его часть приходится на бренд.

   На каждое ключевое слово рисуется свой график динамики за 12 месяцев. Пустые строки
   игнорируются, подпись можно не заполнять — подставится сам ключ.
5. «Собрать отчёт» → откроется страница отчёта. Кнопка «Скачать HTML» сохраняет
   автономный файл: открывается без сервера, можно отправить клиенту.

Закончили — просто закройте чёрное окно.

## Что важно знать про цифры в отчёте

- **Незакрытые недели не считаются недоосвоением.** В файле план расписан на все недели
  месяца, а факт заполняется только по прошедшим. Если считать «% от плана» по месяцу
  целиком, выйдет ложный минус. Отчёт считает выполнение только по неделям, где факт
  бюджета > 0, остальные помечает «неделя не завершена» и ставит «нет данных».
- **KPI не складывается между моделями закупки.** Просмотры (CPV), показы (CPM) и клики
  (CPC) суммируются только внутри своей модели.
- **Цена единицы** — бюджет с НДС и АК, делённый на объём: за 1000 показов для CPM,
  за просмотр/клик для CPV/CPC. Это эффективная цена по факту, а не ставка закупа.
- **Google Keyword Planner по кириллице уже подводил** (на паре «стопдиар»/«диарея»
  бренд показал больше объёма, чем категория). Числа помечены источником, в отчёте есть
  сноска «перепроверять по Wordstat». Если объёмов нет — отчёт пишет «нет данных»,
  а не подставляет выдуманное число.
- **Хвост нулей у графика спроса обрезается**: Google отдаёт 0 за последние 1-2 месяца
  из-за отчётной задержки, это не падение спроса.

## Ключи (файл `.env` в этой папке)

| Ключ | Зачем | Если не задан |
|---|---|---|
| `APIFY_API_TOKEN` | спрос из Google Keyword Planner (~$0.012 за ключевое слово) | блок спроса пишет «нет токена», отчёт собирается |
| `ANTHROPIC_API_KEY` | выводы от Клода | вместо выводов арифметический разбор с пометкой «без Клода» |
| `PBA_AI_MODEL` | необязательно, по умолчанию `claude-sonnet-5` | — |
| `PBA_USER` / `PBA_PASSWORD` | пароль на сайт при выкладке на хостинг | локально не нужен; на хостинге без пароля сайт отвечает 503 |

Статус ключей видно на самой странице внизу четвёртого блока — там же написано,
какой источник сейчас недоступен.

На этой машине оба ключа уже вписаны в `.env`: Apify перенесён из
`gedeon-richter\wordstat-dashboards\.env`, ключ Anthropic — из бэкапа
Digital Audit Tool. Файл `.env` в git не попадает.

## Выкладка на хостинг (Railway)

Сайт готов к деплою: `Procfile` и `.python-version` в корне, версии зависимостей
зафиксированы в `requirements.txt`.

1. Залить репозиторий на GitHub (без `.env` — он в `.gitignore`).
2. В Railway: New Project → Deploy from GitHub repo → выбрать этот репозиторий.
3. В разделе Variables вписать **самому** (Claude ключи в чужие панели не вводит):
   `APIFY_API_TOKEN`, `ANTHROPIC_API_KEY`, `PBA_USER`, `PBA_PASSWORD`.
4. Открыть выданный домен, браузер спросит логин и пароль из `PBA_USER`/`PBA_PASSWORD`.

**Что защищает сайт снаружи:**

- пароль на весь сайт, включая просмотр и скачивание отчётов (в них бюджеты клиента).
  Локальный запуск через `start.bat` пароля не требует — проверяется адрес клиента;
- если `PBA_PASSWORD` на хостинге не задан, сайт отвечает 503, а не открывается всем;
- не больше 12 ключевых слов на отчёт и 20 сборок в час с одного адреса — это прямая
  защита кошелька: каждый ключ платный запрос в Apify;
- в памяти держатся последние 30 загрузок и 30 отчётов, старые файлы удаляются;
- парсер отказывается читать файлы с более чем 24 листами или 4000 строк на листе
  (защита от распухших и специально сломанных xlsx);
- наружу уходит общее сообщение об ошибке, детали остаются в логах.

Диск на Railway эфемерный: после редеплоя `uploads/` пустой, ссылки на прошлые отчёты
не работают. Скачанные HTML-файлы от этого не зависят.

## Какой файл понимает парсер

Выгрузка AMK, weekly или monthly — без разницы, читаются все листы-месяцы:

```
Клиент: | ТОО «Gedeon Richter KZ»
Бренд:  | Стопдиар
Период: | 2026-08-01
тотал                                  <- блок «месяц целиком по площадкам»
Платформа | Формат | Формат закупки | KPI (план/факт/разница/%) | Бюджет с НДС и АК (план/факт/разница)
  ...строки размещений...
Всего                                  <- итог блока
1 неделя | 25.07 - 02.08               <- блок недели
  ...
```

Если структура поменяется (сдвинутся колонки, переименуются блоки) — отчёт честно
откажется читать файл, а не посчитает мусор. Тогда покажите новый файл Клоду.

## Устройство кода

```
start.bat            запуск в один клик (venv, зависимости, сервер, браузер)
app/main.py          FastAPI: загрузка файла, сборка отчёта, страница и скачивание
app/pba_parser.py    разбор xlsx -> структура месяцев, недель и площадок
app/search_demand.py Google Keyword Planner через Apify (числовой geo, KZ = 2398)
app/ai_summary.py    выводы Клода через tool use + арифметический fallback
app/report_html.py   рендер автономного HTML отчёта
app/security.py      пароль на сайт, лимиты частоты и числа ключевых слов
app/static/index.html интерфейс (один файл, без сборки)
uploads/             загруженные xlsx (в git не попадают)
Procfile             команда запуска для хостинга
```

Отчёты живут в памяти процесса: перезапустили сервер — ссылки на прошлые отчёты
перестают работать, но xlsx остаются в `uploads/`, и отчёт собирается заново за минуту.
Уже скачанные HTML-файлы от перезапуска не зависят.

Родственные инструменты по этому клиенту лежат в
`Рабочий стол\проекты\gedeon-richter\` (дэшборды динамики запросов по Wordstat
и сами файлы ПБА).
